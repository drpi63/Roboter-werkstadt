# Roboter-Werkstatt

Lern-App rund um Roboter von Dr. Piczlewicz: Nori bauen und trainieren, Bot-Labor, Roboter-Baukasten, Stab-Balance, Bauteile-Atlas und ein Abschluss-Quiz mit Testat.

Läuft komplett im Browser, auch offline. Auf dem Handy über „Zum Startbildschirm hinzufügen“ installierbar.

Lokal: Ordner herunterladen und `index.html` im Browser öffnen.

Web-Adresse: https://drpi63.github.io/Roboter-werkstadt/
